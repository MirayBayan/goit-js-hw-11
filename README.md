# JavaScript Ödevi: Pixabay Görsel Arama Motoru

Bu proje, Pixabay API kullanılarak geliştirilmiş dinamik bir web uygulamasıdır. Kullanıcıların anahtar kelimelerle yüksek kaliteli görseller aramasını sağlar ve anlık geri bildirim sunan modern, duyarlı bir arayüze sahiptir.

## 🚀 Genel Bakış

Uygulama aşağıdaki konulardaki becerileri göstermektedir:

- Asenkron Programlama: Fetch API ve Promise yapıları kullanılarak HTTP isteklerinin yönetilmesi.
- API Entegrasyonu: Sorgu parametrelerinin yönetilmesi ve üçüncü taraf bir REST API'den gelen JSON verilerinin işlenmesi.
- Kullanıcı Arayüzü ve Deneyimi (UI/UX): Yüklenme durumlarının gösterilmesi, modal galeri yapısının uygulanması ve özelleştirilmiş bildirim sistemlerinin kullanılması.

## 🛠 Kullanılan Teknolojiler

- Paketleyici: Vite
- Kütüphaneler:
  - iziToast: Hata ve uyarılar için özelleştirilmiş açılır bildirimler.
  - SimpleLightbox: Dokunmatik ekranlarla uyumlu, duyarlı görsel yakınlaştırma ve görseller arasında gezinme.
- Stil: Montserrat yazı tipine odaklanan, temiz ve modern bir ızgara düzenine sahip özel CSS tasarımı.
- API: Pixabay API
